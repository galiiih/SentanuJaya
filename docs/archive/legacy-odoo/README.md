# Arsip Referensi Legacy Odoo

Folder ini menyimpan beberapa dokumen dan konfigurasi dari versi lama Sentanu Jaya berbasis Odoo 17.

**Penting:** arsip ini bukan sumber implementasi aktif. Aplikasi ERP yang berlaku berada pada struktur `backend/` (Laravel) dan `frontend/` (React). Jangan menjalankan `docker-compose.yml` atau script di arsip ini untuk menyiapkan aplikasi saat ini. Alur bisnis pada dokumen lama harus dicocokkan dengan keputusan Owner terbaru dan source code aktif.

Sumber yang dipertahankan:
- Blueprint dan panduan operasional lama.
- Handoff teknis Odoo.
- README dan Docker Compose Odoo sebagai catatan historis.
- Diagram alur bisnis yang lama.
- Script bantu yang khusus untuk Odoo.

Kode addon Odoo lama tidak lagi ditempatkan pada branch aktif; riwayat branch sebelumnya tetap menjadi rekam jejak perubahan Git.
